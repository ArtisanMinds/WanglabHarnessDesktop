# Wanglab 前端品牌与本地化记录

状态：进行中  
基线：Wanglab Harness Desktop 0.6.0 / 上游 DeepSeek Harness Desktop 0.16.0  
检查日期：2026-09-24

## 产品用语

用户可见文案统一使用以下名称：

| 含义 | 固定用语 |
| --- | --- |
| 桌面产品 | Wanglab Harness Desktop |
| 主界面或运行服务 | Wanglab Harness |
| 托管的运行内核 | Wanglab Harness Core |
| 组织 | 按服务归属使用 Wanglab 或 WanglabAI |
| 产品标语 | Create Future Here. |

以下技术标识涉及兼容性，保持原值：

- `dsh`、`DSH_HOME`、`dsh://`、包名、npm scope、命令、配置键、URL、存储键和 Tauri command。
- `@deepseek-ai/*` 依赖名及 DeepSeek 模型提供商名称。
- 第三方插件发布者定义的插件名称和标识。

## 0.6.0 品牌修正

桌面壳层已在启动页、iframe 标题、更新提示、启动和恢复错误、配置导航、Core 管理页及 About 对话框统一使用 Wanglab 名称。首次启动的 About Us 同时介绍 Wanglab Harness 和 Wanglab，不再显示上游内测声明。

About 对话框此前调用了未定义的 `about.slogan` 和 `about.website`，界面会直接显示翻译 key。两项现已在中英文词典中补齐。

## 本地化检查

修正前，桌面壳层中英文词典各有 359 个 key，双方不存在缺项。全面本地化阶段仍需处理以下范围：

| 优先级 | 范围 | 当前问题 | 完成标准 |
| --- | --- | --- | --- |
| P0 | 启动壳层 | 本轮品牌修正后，中文词典仍有 12 条启动、内置插件检查和阶段名称使用英文。 | `zh-CN` 全部使用自然中文，`en-US` 使用自然英文。 |
| P0 | Core 内嵌界面 | 会话、工作区和上游设置的大部分文案由 Core 包在运行时提供，不属于 Desktop 词典。 | 使用配套 Core 分别遍历中英文主流程，登记并消除全部未翻译文案。 |
| P0 | 内置插件 | 各插件分别维护 `defineLocale` 词典，Desktop key 对齐检查覆盖不到插件。 | 检查每个内置插件词典，并以两种语言实际渲染主要面板。 |
| P1 | 运行错误 | Rust、Node 和第三方依赖可能在稳定错误码之后直接显示英文技术详情。 | 已知错误码提供本地化摘要，同时保留原始详情用于诊断。 |
| P1 | 布局 | 中英文、模型 ID、路径和插件包名的长度差异很大。 | 在 860px 和 1440px 下无截断、重叠或控件尺寸跳动。 |
| P1 | About Us | 产品要求两种语言均显示同一份英文介绍。 | 除非产品策略变更，否则保持英文内容一致。 |
| P2 | UI playground | 仅开发环境使用的组件示例含硬编码中文。 | 保持不进入生产，或在公开该面板前完成本地化。 |

## 每批验收

1. Desktop 中英文词典 key 完全一致。
2. `src/` 内所有静态 `t('key')` 均能解析到 Desktop 词典。
3. 用户可见产品文案不再出现 `DeepSeek Harness` 或未限定的 `Harness`；上述技术标识不计入。
4. 两种语言分别覆盖首次启动、正常启动、失败页、About、设置、Core 管理和全部内置插件面板。
5. 860px 与 1440px 截图不存在截断、重叠或翻译 key 回退。
