# Wanglab 前端品牌与本地化记录

状态：进行中  
基线：Wanglab Harness Desktop 0.7.1 / 上游 DeepSeek Harness Desktop 0.17.0
检查日期：2026-09-24

## 产品用语

用户可见文案统一使用以下名称：

| 含义 | 固定用语 |
| --- | --- |
| 桌面产品 | Wanglab Harness Desktop |
| 主界面或运行服务 | Wanglab Harness |
| 托管的运行内核 | Wanglab Harness Core |
| 组织 | 按服务归属使用 Wanglab 或 WanglabAI |
| 产品标语 | Create Future Here. |

以下技术标识涉及兼容性，保持原值：

- `dsh`、`DSH_HOME`、`dsh://`、包名、npm scope、命令、配置键、URL、存储键和 Tauri command。
- `@deepseek-ai/*` 依赖名及 DeepSeek 模型提供商名称。
- 第三方插件发布者定义的插件名称和标识。

## 0.6.0 品牌修正

桌面壳层已在启动页、页面标题、iframe 标题、更新提示、启动和恢复错误、配置导航、Core 管理页、系统权限提示及 About 对话框统一使用 Wanglab 名称。首次启动的 About Us 同时介绍 Wanglab Harness 和 Wanglab，不再显示上游内测声明。

首次引导与插件设置会直接展示 `internal-plugins.json`、`preset-plugins.json` 或开发模式插件 `package.json` 中的描述。本轮已同步修正这些入口，避免主界面完成品牌替换后仍从插件元数据漏出上游产品名。

About 对话框此前调用了未定义的 `about.slogan` 和 `about.website`，界面会直接显示翻译 key。两项现已在中英文词典中补齐。

## 0.7.1 会话身份修正

此前的品牌检查只覆盖 Desktop 壳层，没有覆盖配套 Core 组装并发送给模型的系统提示词，也没有覆盖聊天界面展示的上下文注入来源。因此真实会话仍会显示 `DeepSeek Harness`、固定模型身份和 `@deepseek-ai/dsh-system-prompt`。

0.7.1 将 Core 身份改为 `Wanglab Harness`，各代理预设改为使用用户选择的模型提供方，并把系统上下文来源显示为 `Wanglab Harness`。npm 包名、导入路径和持久化消息中的插件标识保持不变，以兼容依赖解析和已有会话。构建检查同时覆盖 Web、Standard、PTC、Cordis、SDK、ACP 与 Headless 预设，并直接检查最终 Windows Core 压缩包中的提示词与显示映射。

## 本地化检查

修正前，桌面壳层中英文词典各有 359 个 key，双方不存在缺项。全面本地化阶段仍需处理以下范围：

| 优先级 | 范围 | 当前问题 | 完成标准 |
| --- | --- | --- | --- |
| P0 | 启动壳层 | 本轮品牌修正后，中文词典仍有 12 条启动、内置插件检查和阶段名称使用英文。 | `zh-CN` 全部使用自然中文，`en-US` 使用自然英文。 |
| P0 | 页面语言状态 | `index.html` 固定声明 `lang="zh-CN"`，桌宠气泡还会在模块初始化时据此固化语言；切换英文后，辅助技术与气泡可能仍按中文处理。 | 语言 Store 成为唯一来源，每次切换同步更新 `document.documentElement.lang`，气泡在渲染时读取当前语言。 |
| P0 | Core 内嵌界面 | 会话、工作区和上游设置的大部分文案由 Core 包在运行时提供，不属于 Desktop 词典。 | 使用配套 Core 分别遍历中英文主流程，登记并消除全部未翻译文案。 |
| P0 | 内置插件 | 各插件分别维护 `defineLocale` 词典，Desktop key 对齐检查覆盖不到插件。 | 检查每个内置插件词典，并以两种语言实际渲染主要面板。 |
| P0 | 插件描述 | 首次引导与插件设置读取单语资源清单，当前描述只有英文，没有 locale 字段。 | 为清单建立中英文结构或稳定翻译 key，禁止在组件里按文本判断语言。 |
| P1 | 运行错误 | Rust、Node 和第三方依赖可能在稳定错误码之后直接显示英文技术详情。 | 已知错误码提供本地化摘要，同时保留原始详情用于诊断。 |
| P1 | 页面元数据 | 静态 `<title>` 已完成品牌修正，但不会跟随应用语言变化。 | 由 i18n 初始化和语言切换统一设置标题及页面语言。 |
| P1 | 布局 | 中英文、模型 ID、路径和插件包名的长度差异很大。 | 在 860px 和 1440px 下无截断、重叠或控件尺寸跳动。 |
| P1 | About Us | 产品要求两种语言均显示同一份英文介绍。 | 除非产品策略变更，否则保持英文内容一致。 |
| P2 | UI playground | 仅开发环境使用的组件示例含硬编码中文。 | 保持不进入生产，或在公开该面板前完成本地化。 |

## 每批验收

1. Desktop 中英文词典 key 完全一致。
2. `src/` 内所有静态 `t('key')` 均能解析到 Desktop 词典。
3. 用户可见产品文案不再出现 `DeepSeek Harness` 或未限定的 `Harness`；上述技术标识不计入。
4. 两种语言分别覆盖首次启动、正常启动、失败页、About、设置、Core 管理和全部内置插件面板。
5. 860px 与 1440px 截图不存在截断、重叠或翻译 key 回退。
6. 页面 `lang`、标题、桌宠气泡和当前应用语言保持一致。
